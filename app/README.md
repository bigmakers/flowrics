# Flowrics Web

YouTube の動画を背景に、LRCLIB の同期歌詞を弾幕風に流す Flowrics のブラウザ版。`index.html` 1 ファイルで完結し、ビルド工程はない。

## 公開先

| 場所 | URL | 反映方法 |
|---|---|---|
| GitHub Pages | https://bigmakers.github.io/flowrics/app/ | `main` に push すると自動 |
| ロリポップ！デプロイナウ | https://flowrics.lolipop-now.app | `./app/deploy.sh` |

デプロイナウへは `lolipop` CLI (`npm i -g lolipop`) で `static` フレームワークとして出す。初回は `deploy.sh` の `PROJECT` を空のまま実行するとプロジェクトが作られるので、表示された project ID を `PROJECT` に書き込む。

## 使い方

1. 右上の ☰ → キューに YouTube の URL を貼って追加。動画 URL(watch / youtu.be / Shorts)なら 1 曲、プレイリスト URL(`list=…`)なら全曲が入る(IFrame Player API の `cuePlaylist` → `getPlaylist()` で ID を取るので API キー不要)
   - キューに名前を付けて保存すると「保存したプレイリスト」から呼び出せる(ブラウザの localStorage に保存)
   - タイトルとチャンネル名は YouTube の oEmbed(CORS 可・キー不要)で取得する
2. 動画タイトルから曲名・アーティストを推定して LRCLIB を検索し、同期歌詞を自動で流す
3. 合わなければ「歌詞」タブで候補を切り替える、曲名を直して再検索する、LRC を貼り付ける、オフセットで微調整する

`?v=ID1,ID2` の形でキューを、`?list=PL…` の形で YouTube プレイリストを URL 共有できる。設定とキューは localStorage に保存される。

## 弾幕の描画

iOS 版(musicSUB リポジトリの `DanmakuView.swift`)をそのまま移植している。

- 1 行を 4 層で流す: プレビュー(−1 秒, 50%, 0.8 倍) → メイン → エコー(+2 秒, 25%, 0.7 倍) → ゴースト(+5 秒, 15%, 0.5 倍)
- 文字種ごとの組版: 漢字 2 倍・極太、ひらがな 1 倍・細字、カタカナ 1.4 倍・太字イタリック、英語は重要語 2 倍・機能語(冠詞・代名詞など)1 倍。ベースラインで揃える
- 高さはランダム(レーンなし)、画面横断は既定 8 秒、歌詞は 0.4 秒先行して発射、2 秒以上のシークで全消去
- 文字サイズ: 混(12/20/32/48/64 からランダム) / 中 20 / 大 32 / 特大 64。既定フォントはクレー(Klee One)
- 背景色 6 色(ブラック / ターコイズ / オレンジ / レッド / ホワイト / ベージュ)に応じて文字色と影色が変わる。動画は背景色の下に透けて見える(暗さスライダーで調整)

## YouTube 検索(任意)

YouTube Data API v3 をブラウザから直接呼ぶ(埋め込み可能な動画のみ、結果は 24 時間キャッシュ)。無料枠が 1 日約 100 検索しかなく、公開サイトで共有するには足りないので `DEFAULT_YT_KEY` は空のままにしてある。利用者が設定タブに自分のキーを入れた場合だけ結果がアプリ内に出る。キーがないときは YouTube の検索結果ページを新しいタブで開き、URL を貼る導線に落とす。

## 制約

- YouTube の規約上、音声だけの再生はできない。動画をそのまま背景に表示する
- 埋め込みが許可されていない動画(エラー 101/150)は再生できず次の曲へスキップする
- 歌詞は LRCLIB にある曲だけ。プレイリストの取り込みは公開・限定公開のものに限られ、1 回で最大 200 曲(YouTube 側の上限)
